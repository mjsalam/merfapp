Merf Support

Get started

Open Merf and choose a folder for your scraps. Click its menu bar icon or press Control–Shift–Space to open the drawer. Choose a different shortcut in Settings if another app already uses that combination.

Capture something

Press Command–N while Merf is active to write a note. Command–Return saves it. Right-click the menu bar icon and choose Capture Clipboard for copied text, files, or images. Drop individual files onto the drop area inside the drawer, or click that area to choose files. Original files are preserved. If dragging toward the menu bar opens Mission Control, use the drawer drop area instead.

Find your files

Scraps are saved as normal files in the folder you selected. The folder button reveals the current file in Finder. Merf supports text and Markdown notes; clipboard images are saved as PNG files. Rich previews depend on macOS Quick Look and the file type.

Troubleshooting

If the drawer will not open, click the menu bar icon and check Settings for a shortcut conflict. If a folder is unavailable, choose it again. For an unsupported preview, use Open file to view it in its usual app. Ordinary subfolders are not included in the collection.

Contact

Email support@getmerfapp.com for help with Merf. Include your macOS version, Merf version, and the steps that led to the problem. Please avoid sending sensitive files.
